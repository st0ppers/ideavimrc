# Dotfiles

## Nvim
### Prerequisites

- GCC compiler 
- Unzip (sudo apt install unzip)
- NPM 

### Installation

1. Install Neovim
`sudo apt install neovim`

2. Install NPM
` curl -o- https://raw.githubusercontent.com/nvm-sh/nvm/v0.39.5/install.sh | bash
source ~/.bashrc
nvm install --lts
nvm use --lts `

3. Unzip
` sudo apt install -y unzip`( sudo apt update )

4. GCC
` sudo dnf install -y gcc`( sudo dnf update )
